1 Semi-Final Structure
▼
The Semi-Final contains exactly 4 questions (NOT 5). Each question has exactly 5 intentional errors (20 errors total).
2 Python 3 Fundamentals Only
▼
Standard Python 3 only: variables, lists, nested lists/matrices, loops, conditionals, accumulators, and functions. No external packages (NumPy/Pandas) required.
3 IDE Debugging Workflow
▼
Click [ COPY CODE ] on the left, paste into your local Python IDE, debug and run, then paste your corrected code into the right panel and click [ VERIFY CODE ].

▼
Clicking [ VERIFY CODE ] evaluates your code (showing green for success or red for unverified). Clicking verify automatically unlocks the [ NEXT QUESTION ] button so you can proceed at any time. You can also skip or retry.
5 Timing & Early-Exit Threshold
▼
Total Semi-Final time is 60 minutes. Early exit becomes available after 45 minutes (or immediately if all 4 questions are solved). Hard stop at 60:00.
6 Multi-Participant Support
▼
After finishing the test, coordinators or candidates can click [ + REGISTER ANOTHER PARTICIPANT ] to safely archive current results and initialize a fresh test session for the next student.
