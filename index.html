2 PROGRAMMING LANGUAGE
▼
The debugging questions use Python 3. Only standard Python 3 concepts are required: Variables, Lists, Nested Lists / Matrices, Loops, Conditional Statements, Accumulators, Functions, and basic operators. No external packages are required. NumPy and Pandas are NOT required.
