# Technothirst’26 — Python Debugging Championship

**A.V.C. College of Engineering (Autonomous)**  
*Department of Computer Applications (MCA) — Mannampandal, Mayiladuthurai*

An offline-first, client-side Python 3 Debugging Championship application built strictly with modern web fundamentals (**HTML5**, **CSS3**, and **Vanilla JavaScript**). 100% offline, zero external dependencies, zero Node/npm requirements, zero CDN fonts, and pen-drive ready.

---

## 🚀 Key Highlights

- **100% Pen-Drive Ready**: Simply copy the `TECHNOTHIRST26_DEBUGGING` folder to any USB pen drive, paste on any computer, double-click `index.html`, and it runs instantly with full functionality.
- **Stage 1: Semi-Final Examination**:
  - Exactly **4 questions** with **5 intentional errors** each (20 errors total).
  - 60-minute countdown timer with early-exit unlocks at 45:00 or when all 4 questions are solved.
  - Interactive multiple-choice diagnosis with instant answer verification.
  - Emerald/Rose feedback banners, technical bug breakdowns, and corrected code.
  - Duplicate scoring prevention (points increment exactly once).
- **Stage 2: Coordinator Approval Gate**:
  - Unlocked via coordinator credentials (`Admin@Debug2026` or `MCALAB@2k26`).
  - Pre-populates qualified candidate details.
  - Auto-assigns sequential Finalist IDs (`TT26-F001`, `TT26-F002`...).
  - Persistent offline database table in `localStorage`.
  - One-click JSON Export & Import for seamless data merging across multiple offline lab machines.
- **Stage 3: Championship Final Round**:
  - 2 High-level Python debugging questions (10 minutes total).
  - Cumulative Championship Scorecard (60 points max).
- **Official Print / PDF Certificates**:
  - Clean `@media print` layout for saving or printing official merit scorecards.
